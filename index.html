RandomItems

Поставьте блок, нажмите на него правой кнопкой мыши. Житель простонет, а над блоком выпадет случайный предмет из игры.

100 ₽Бесплатно, если у вас есть код

Скачать бесплатно

Для Minecraft 1.21.11, нужен Fabric и Java 21

Нажмите на блок и посмотрите, что выпадет

Как установить

  1. Установите Fabric Loader для Minecraft 1.21.11Установщик есть на сайте fabricmc.net

  2. Положите RandomItems.jar и Fabric API в папку modsПапка находится в .minecraft, Fabric API нужен той же версии 1.21.11

  3. Запустите игру и найдите блок в творческом режимеОн лежит во вкладке «Строительные блоки»
